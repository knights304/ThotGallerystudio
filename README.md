# Thot Gallery Creator v2 Foundation

This checkpoint migrates the reusable Alpha 7 source into the first reproducible Creator v2 foundation.

The existing black, purple, and silver interface is preserved. The project now includes bootstrap and verification scripts, repaired test setup, dependency pins, and the official v2 card-family identifiers.

Start with `INSTALL.md`, then record any terminal output if a check fails. Do not add new production features until the foundation launches successfully on the Galaxy Tab S6.
